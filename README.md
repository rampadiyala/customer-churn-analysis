# Customer Churn Analysis

Exploring churn by contract type and tenure.

## Features

- Fills missing tenure values with the median
- Compares churn rates by group
- Saves bar charts

## Tech stack

Python, NumPy, Pandas, Matplotlib

## How to run

`pip install -r requirements.txt`, then `python analysis.py`.

## Project files

- `analysis.py` - data generation, cleaning and charts
- `churn_by_*.png` - output charts

## Notes

The data is randomly generated with built-in churn patterns, so results are not real findings.
